チートシート

よく使う構文のまとめ。困ったときの早見表に。

変数・型

int n = 10;
double d = 1.5;
boolean b = true;
String s = "文字";
final int MAX = 100;

条件分岐

if (x > 0) { ... }
else if (x == 0) { ... }
else { ... }

String r = (x > 0) ? "正" : "負";

繰り返し

for (int i = 0; i < n; i++) {}
for (int x : arr) {}
while (cond) {}

配列

int[] a = {1, 2, 3};
a[0] = 9;
int len = a.length;
int[] b = new int[5];

メソッド

static int add(int a, int b) {
    return a + b;
}
void run() { ... } // 戻り値なし

クラス

class Dog {
    String name;
    Dog(String n) { name = n; }
    void bark() { ... }
}
Dog d = new Dog("ポチ");

List / Map

List list = new ArrayList<>();
list.add("a");
Map m = new HashMap<>();
m.put("key", 1);

例外処理

try {
    risky();
} catch (Exception e) {
    System.out.println(e.getMessage());
}

文字列

s.length();
s.substring(2);
s.equals(t);   // 比較は equals!
s.split(",");

用語集

つまずきやすい用語を、ひとことで。

変数
データを入れておく名前付きの箱。
型（データ型）
データの種類。int（整数）、String（文字列）など。
メソッド
名前をつけてまとめた処理。関数のこと。
引数（ひきすう）
メソッドに渡す入力データ。
戻り値（もどりち）
メソッドが返す結果。return で返す。
クラス
オブジェクトの設計図。データと処理をまとめたもの。
オブジェクト / インスタンス
クラスから new で作った実物。
フィールド
クラスが持つデータ（変数）。属性。
コンストラクタ
new 時に呼ばれる初期化用の特別なメソッド。
this
「自分自身のオブジェクト」を指すキーワード。
継承
既存クラスの機能を引き継いで新クラスを作ること（extends）。
オーバーライド
親クラスのメソッドを子クラスで上書きすること。
オーバーロード
同じ名前で引数違いのメソッドを複数定義すること。
インターフェース
「できること」だけを定めた約束（implements）。
カプセル化
データを隠してメソッド経由で操作させ、安全にする考え方。
ポリモーフィズム
同じ呼び出しが対象の型で違う動きをすること（多態性）。
例外
実行中に起きるエラー。try-catchで対処する。
コレクション
List・Map・Setなど、データをまとめて扱う道具。
ジェネリクス
型を後から指定できる仕組み。List<String> など。
コンパイル
ソースコードを機械が実行できる形式に変換すること。
JVM
Java仮想マシン。バイトコードを実行する土台。
API
あらかじめ用意された機能の呼び出し口（標準ライブラリなど）。
