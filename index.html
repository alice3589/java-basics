1. Javaとは / 環境構築

Java は世界中で広く使われているプログラミング言語です。Androidアプリ、銀行や企業の業務システム、大規模Webサービスなど活躍の場が非常に広く、一度学べば長く役立ちます。

Javaの3つの特徴

🧩オブジェクト指向

プログラムを「モノ（オブジェクト）」の集まりとして組み立てる。大きなソフトでも整理しやすい。

🌍どこでも動く

「一度書けば、どこでも動く」。WindowsでもMacでもLinuxでも同じコードが動く。

🛡️静的型付け

変数の型を先に決めるので、間違いをコンパイル時に発見できる。安全で堅牢。

仕組み：コンパイルと実行

Javaのソースコード（.java）は コンパイル されて中間形式（.class＝バイトコード）になり、それを JVM（Java仮想マシン） が実行します。この「JVMが間に入る」仕組みのおかげで、どのOSでも動きます。

javac→

環境構築（JDKのインストール）

自分のPCでJavaを動かすには JDK（Java Development Kit） が必要です。無料の Temurin（Adoptium） がおすすめ。インストール後、ターミナルで確認します。

java -version
javac -version
💡 バージョン番号が出ればOK。エディタは VS Code（拡張「Extension Pack for Java」）か IntelliJ IDEA が定番。

2. 最初のプログラム（Hello World）

まずは画面に文字を表示する定番から。下のコードの 「▶ 実行」 を押してみてください。結果がすぐ下に表示されます。コードを書き換えて再実行もできます（「✎ 編集」）。

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
        System.out.println("はじめてのJava！");
    }
}

コードの意味

  • public class Main … クラスの定義。プログラムの入れ物
  • public static void main(String[] args) … プログラムの入口（mainメソッド）。実行するとここから始まる
  • System.out.println(...) … 画面に1行表示。printlnは改行あり、printは改行なし
  • 文の終わりには必ず セミコロン ;
💡 自分のPCで動かす場合はファイル名とクラス名を一致させます（public class Hello なら Hello.java）。コンパイルは javac Hello.java、実行は java Hello。

3. 変数とデータ型

変数はデータを入れておく「箱」。Javaでは箱を作るときに型（データの種類）を指定します。

int age = 20;             // 整数
double height = 170.5;    // 小数
char grade = 'A';         // 1文字（シングルクォート）
boolean isStudent = true; // 真偽値（true / false）
String name = "佐藤";      // 文字列（ダブルクォート）

System.out.println(name + "さん / " + age + "歳 / 評価" + grade);

基本データ型（プリミティブ型）

型用途例
int整数100, -5
long大きな整数10000000000L
double小数3.14, -0.5
char1文字'A', 'あ'
boolean真偽値true, false

String（文字列）はプリミティブ型ではなくクラスですが、基本としてよく使います。

定数とキャスト（型変換）

final double PI = 3.14159;  // final = 変更できない定数
// PI = 3.0;  // ← これはエラー

int i = 10;
double d = i;       // int → double は自動変換（10.0）
double pi = 3.99;
int n = (int) pi;   // double → int は明示キャスト（小数切り捨て → 3）

System.out.println(d + " / " + n + " / " + PI);
💡 変数名は意味の分かる英単語で。Javaの慣習は userName のような「キャメルケース」。定数は MAX_SIZE のように大文字＋アンダースコア。

4. 演算子

算術演算子

int a = 7, b = 3;
System.out.println(a + b); // 10  足し算
System.out.println(a - b); // 4   引き算
System.out.println(a * b); // 21  掛け算
System.out.println(a / b); // 2   割り算（整数同士は切り捨て！）
System.out.println(a % b); // 1   余り（あまり）
System.out.println(7.0 / 3); // 2.333... 片方が小数なら小数で計算

代入・インクリメント

int n = 10;
n += 5;  System.out.println(n); // 15
n -= 3;  System.out.println(n); // 12
n *= 2;  System.out.println(n); // 24
n++;     System.out.println(n); // 25（1増やす）
n--;     System.out.println(n); // 24（1減らす）

比較・論理演算子（結果は boolean）

int x = 5;
System.out.println(x == 5);  // true   等しい
System.out.println(x != 3);  // true   等しくない
System.out.println(x > 3);   // true   より大きい
System.out.println(x <= 5);  // true   以下

boolean p = true, q = false;
System.out.println(p && q);  // false  かつ（AND）
System.out.println(p || q);  // true   または（OR）
System.out.println(!p);      // false  否定（NOT）
⚠️ 整数同士の割り算は要注意！ 5 / 2 は 2（小数は切り捨て）。2.5 がほしいなら 5.0 / 2 とします。上のコードで確かめてみよう。

5. 標準入出力

出力

System.out.println("改行あり");
System.out.print("改行");
System.out.print("なし\n");                  // \n で改行
System.out.printf("%sは%d歳%n", "佐藤", 20);  // 書式つき出力

キーボードから入力（Scanner）

このコードは入力を必要とします。実行パネルの「標準入力」欄にあらかじめ値が入っています（自由に変えてOK）。

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("名前を入力: ");
        String name = sc.nextLine();   // 1行（文字列）を読む

        System.out.print("年齢を入力: ");
        int age = sc.nextInt();        // 整数を読む

        System.out.println(name + "さんは" + age + "歳です");
        sc.close();
    }
}
  • nextLine() … 1行（文字列）を読む / nextInt() … 整数 / nextDouble() … 小数
  • 文字列の連結は +
💡 import java.util.Scanner; は「Scannerという道具を使う」宣言。ファイルの先頭に書きます。

6. 条件分岐 (if / switch)

if 文

int score = 75;

if (score >= 80) {
    System.out.println("優");
} else if (score >= 60) {
    System.out.println("良");
} else {
    System.out.println("不可");
}

三項演算子（短い条件分岐）

int n = 4;
String result = (n % 2 == 0) ? "偶数" : "奇数";
System.out.println(result); // 偶数

switch 文・switch式

int day = 3;

// 新しい書き方（switch式）：すっきり書ける
String name = switch (day) {
    case 1 -> "月曜";
    case 2 -> "火曜";
    case 3 -> "水曜";
    default -> "その他";
};
System.out.println(name); // 水曜
⚠️ 従来の switch(){ case ...: break; } では break; を忘れると次のcaseまで実行されます（フォールスルー）。新しい -> 形式ならその心配はありません。

7. 繰り返し (for / while)

for 文

// 1から5まで表示
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

構造： for (初期化; 続ける条件; 更新)

while / do-while

int i = 1;
while (i <= 3) {
    System.out.println("while: " + i);
    i++;  // ← 忘れると無限ループ！
}

int n = 3;
do {
    System.out.println("do-while: " + n); // 最低1回は実行される
    n--;
} while (n > 0);

break と continue

for (int i = 1; i <= 10; i++) {
    if (i == 5) break;        // ループを抜ける
    if (i % 2 == 0) continue; // 次の繰り返しへスキップ
    System.out.println(i);    // 1, 3 を表示
}
💡 回数が決まっているなら for、条件次第で変わるなら while。

8. 配列

配列は同じ型のデータをまとめて扱う入れ物。番号（インデックス）は 0から始まります。

0123
80907560
int[] scores（length = 4）
int[] scores = {80, 90, 75, 60};

System.out.println(scores[0]);     // 80（最初は0番目）
System.out.println(scores.length); // 4（要素数）

scores[1] = 100;                   // 値の書き換え

// 拡張for文（for-each）… 全要素を順番に
for (int s : scores) {
    System.out.println(s);

int[][] table = {

System.out.println(table[1][2]); // 6

9. メソッド

メソッドは処理に名前をつけてまとめたもの。同じ処理を何度も書かずに再利用できます。

public class Main {

    // 戻り値あり：2つの整数を足して返す
    static int add(int a, int b) {
        return a + b;
    }

    // 戻り値なし：void
    static void greet(String name) {
        System.out.println("こんにちは、" + name + "さん");
    }

    public static void main(String[] args) {
        int sum = add(3, 5);     // 呼び出し
        System.out.println(sum); // 8
        greet("田中");
    }
}

メソッドの構造

戻り値の型  メソッド名(引数の型 引数名, ...) {
    処理
    return 戻り値;   // 戻り値がvoidなら不要
}

オーバーロード（同名で引数違い）

public class Main {
    static int add(int a, int b)          { return a + b; }
    static double add(double a, double b) { return a + b; }

    public static void main(String[] args) {
        System.out.println(add(2, 3));     // int版 → 5
        System.out.println(add(2.5, 0.5)); // double版 → 3.0
    }
}
💡 「引数（ひきすう）」＝メソッドに渡す入力、「戻り値（もどりち）」＝返す結果。引数の型・数が違えば同じ名前で複数定義できます（オーバーロード）。

10. クラスとオブジェクト

Javaの中心となる考え方。クラス＝設計図、オブジェクト（インスタンス）＝設計図から作った実物です。たい焼きの型がクラス、焼き上がったたい焼きがオブジェクト。

class Person （設計図）
name, age ← フィールド（持っているデータ）
introduce() ← メソッド（できること）
new →
佐藤 / 20
鈴木 / 25
// 設計図（クラス）
class Person {
    String name;  // フィールド（属性）
    int age;

    // コンストラクタ（生成時に呼ばれる初期化処理）
    Person(String name, int age) {
        this.name = name;  // this = 自分自身のフィールド
        this.age = age;
    }

    // メソッド（振る舞い）
    void introduce() {
        System.out.println("私は" + name + "、" + age + "歳です");
    }
}

public class Main {
    public static void main(String[] args) {
        // 実物（オブジェクト）を作る
        Person p1 = new Person("佐藤", 20);
        Person p2 = new Person("鈴木", 25);

        p1.introduce(); // 私は佐藤、20歳です
        p2.introduce(); // 私は鈴木、25歳です
    }
}
  • フィールド…オブジェクトが持つデータ / メソッド…動作
  • コンストラクタ…new したとき自動で呼ばれる初期化処理
  • this…「自分自身のオブジェクト」

11. カプセル化（アクセス修飾子）

フィールドを外から勝手に書き換えられないように隠し、専用のメソッド（getter/setter）を通してアクセスさせる仕組み。安全なプログラムの基本です。

class BankAccount {
    private int balance = 0;   // private = クラスの外から直接触れない

    public void deposit(int amount) {
        if (amount > 0) {       // 不正な値をチェックできる
            balance += amount;
        }
    }
    public int getBalance() {   // 残高を取得（getter）
        return balance;
    }
}

public class Main {
    public static void main(String[] args) {
        BankAccount acc = new BankAccount();
        acc.deposit(1000);
        acc.deposit(-500);  // 無視される（チェックしているから）
        // acc.balance = 999999; // ← privateなのでコンパイルエラー（守られる）
        System.out.println("残高: " + acc.getBalance()); // 1000
    }
}

アクセス修飾子

修飾子アクセスできる範囲
publicどこからでも
protected同じパッケージ＋サブクラス
(なし)同じパッケージ内
private同じクラス内のみ
💡 「フィールドはprivate、操作はpublicメソッドで」が基本パターンです。

12. 継承

継承は既存クラスの機能を引き継いで新しいクラスを作る仕組み。共通部分を親クラスにまとめられます。

Animalname / eat()
Dogbark()
Cateat() を上書き
class Animal {                 // 親クラス（スーパークラス）
    String name;
    Animal(String name) { this.name = name; }
    void eat() { System.out.println(name + "は食べる"); }
}

class Dog extends Animal {      // 子クラス … extends で継承
    Dog(String name) { super(name); }   // 親のコンストラクタを呼ぶ
    void bark() { System.out.println(name + "はワンと鳴く"); }
}

class Cat extends Animal {
    Cat(String name) { super(name); }
    @Override
    void eat() { System.out.println(name + "は魚を食べる"); } // 上書き(オーバーライド)
}

public class Main {
    public static void main(String[] args) {
        Dog dog = new Dog("ポチ");
        dog.eat();   // 親から継承 → ポチは食べる
        dog.bark();  // 子で追加   → ポチはワンと鳴く

        Cat cat = new Cat("タマ");
        cat.eat();   // 上書き      → タマは魚を食べる
    }
}
💡 @Override は「親のメソッドを上書きします」という目印。書いておくと書き間違いを防げます。super(...) は親のコンストラクタ呼び出し。

13. ポリモーフィズム / 抽象クラス

ポリモーフィズム（多態性）は、同じ呼び出しでもオブジェクトの種類によって違う動きをすること。

abstract class Shape {
    abstract double area();           // 中身なし。子で必ず実装させる
    void show() { System.out.println(getClass().getSimpleName() + "の面積は " + area()); }
}
class Circle extends Shape {
    double r; Circle(double r){ this.r = r; }
    @Override double area(){ return r * r * 3.14; }
}
class Rect extends Shape {
    double w, h; Rect(double w, double h){ this.w = w; this.h = h; }
    @Override double area(){ return w * h; }
}

public class Main {
    public static void main(String[] args) {
        Shape[] shapes = { new Circle(2), new Rect(3, 4) };
        for (Shape s : shapes) {
            s.show();   // 同じ s.show() でも型に応じて結果が変わる
        }
    }
}
💡 抽象クラス（abstract）は「中身が未定のメソッド」を持つ、継承前提のクラス。直接 new できず、子クラスが area() を必ず実装します。

14. インターフェース

インターフェースは「できること（メソッドの一覧）」だけを定めた約束ごと。実装クラスはその約束を必ず守ります。複数同時に実装できるのが強み。

interface Flyable  { void fly();  }
interface Swimmable{ void swim(); }

// implements で実装（複数OK）
class Duck implements Flyable, Swimmable {
    @Override public void fly()  { System.out.println("カモが飛ぶ"); }
    @Override public void swim() { System.out.println("カモが泳ぐ"); }
}

public class Main {
    public static void main(String[] args) {
        Duck duck = new Duck();
        duck.fly();
        duck.swim();
    }
}

抽象クラスとの違い

抽象クラスインターフェース
使い方extends（1つだけ）implements（複数OK）
意味共通の土台（is-a：〜である）できることの約束（can-do：〜できる）

15. enum と record

enum（列挙型）：決まった選択肢を表す

「曜日」「信号の色」「方向」のように、値が決まっているものを型として表せます。タイプミスを防げて安全。

enum Signal { RED, YELLOW, GREEN }

public class Main {
    public static void main(String[] args) {
        Signal s = Signal.RED;

        String action = switch (s) {
            case RED    -> "止まれ";
            case YELLOW -> "注意";
            case GREEN  -> "進め";
        };
        System.out.println(s + " → " + action);

        for (Signal sig : Signal.values()) {  // 全要素を取得
            System.out.println(sig);
        }
    }
}

record：データを入れるだけのクラスを短く

「名前と年齢を持つだけ」のようなデータ専用クラスは、record で1行で書けます（コンストラクタ・getter・toStringなどが自動生成）。

record Point(int x, int y) {}

public class Main {
    public static void main(String[] args) {
        Point p = new Point(3, 4);
        System.out.println(p);        // Point[x=3, y=4]（自動生成）
        System.out.println(p.x());    // 3（getterも自動）
        System.out.println(p.equals(new Point(3, 4))); // true（中身で比較）
    }
}
💡 record はJava 16以降の機能。データの入れ物を作るときに非常に便利です。

16. ジェネリクス

ジェネリクスは「型を後から指定できる」仕組み。List<String> の <String> がそれです。型を固定することで、安全（取り出すときにキャスト不要）になります。

import java.util.ArrayList;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        List names = new ArrayList<>();  // 文字列専用のリスト
        names.add("佐藤");
        // names.add(123);   // ← 型違いはコンパイルエラーで防げる

        String first = names.get(0);  // キャスト不要で安全に取り出せる
        System.out.println(first);
    }
}

自分でジェネリックなクラスを作る

// T は「何かの型」を表すプレースホルダ
class Box {
    private T value;
    public void set(T value) { this.value = value; }
    public T get() { return value; }
}

public class Main {
    public static void main(String[] args) {
        Box sBox = new Box<>();
        sBox.set("こんにちは");
        System.out.println(sBox.get());

        Box iBox = new Box<>();
        iBox.set(100);
        System.out.println(iBox.get() + 1); // 101
    }
}
💡 T は慣習的な名前（Type）。E(Element)、K(Key)、V(Value) などもよく使われます。

17. 例外処理

プログラム実行中のエラー（例外）に対処する仕組み。これがあると、エラーで落ちずに対応できます。

public class Main {
    public static void main(String[] args) {
        try {
            int[] arr = {1, 2, 3};
            System.out.println(arr[10]);  // 範囲外！ 例外発生
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("配列の範囲外です: " + e.getMessage());
        } finally {
            System.out.println("最後に必ず実行される");
        }
        System.out.println("プログラムは続行します");
    }
}
  • try…エラーが起こりそうな処理を囲む
  • catch…例外が起きたときの処理
  • finally…例外の有無に関わらず必ず実行（後片付けに使う）

例外を自分で投げる（throw）

public class Main {
    static int divide(int a, int b) {
        if (b == 0) throw new IllegalArgumentException("0で割れません");
        return a / b;
    }
    public static void main(String[] args) {
        System.out.println(divide(10, 2)); // 5
        try {
            divide(10, 0);
        } catch (IllegalArgumentException e) {
            System.out.println("エラー: " + e.getMessage());
        }
    }
}
⚠️ よく出会う例外： NullPointerException（nullを使った）、NumberFormatException（数値変換失敗）、ArrayIndexOutOfBoundsException（配列範囲外）。

18. コレクション（List / Map / Set）

配列より柔軟にデータを扱える仕組み。サイズが自由に変わります。

ArrayList（順番に並ぶリスト）

import java.util.ArrayList;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        List fruits = new ArrayList<>();
        fruits.add("りんご");
        fruits.add("みかん");
        fruits.add("ぶどう");

        System.out.println(fruits.get(0));  // りんご
        System.out.println(fruits.size());  // 3
        fruits.remove("みかん");

        for (String f : fruits) System.out.println(f);
    }
}

HashMap（キーと値のペア）

import java.util.HashMap;
import java.util.Map;

public class Main {
    public static void main(String[] args) {
        Map scores = new HashMap<>();
        scores.put("佐藤", 80);
        scores.put("鈴木", 95);

        System.out.println(scores.get("鈴木")); // 95

        for (Map.Entry e : scores.entrySet()) {
            System.out.println(e.getKey() + ": " + e.getValue());
        }
    }
}

HashSet（重複なしの集合）

import java.util.HashSet;
import java.util.Set;

Set set = new HashSet<>();
set.add("A");
set.add("A");  // 重複は無視される
set.add("B");
System.out.println(set.size()); // 2
💡 <String> はジェネリクス。「このリストには文字列を入れる」と型を指定しています。

19. 文字列操作

String s = "Hello, Java";

System.out.println(s.length());                  // 11   文字数
System.out.println(s.charAt(0));                 // H    指定位置の文字
System.out.println(s.substring(7));              // Java 部分文字列
System.out.println(s.toUpperCase());             // HELLO, JAVA
System.out.println(s.replace("Java", "World"));  // Hello, World
System.out.println(s.contains("Java"));          // true
System.out.println(s.indexOf("Java"));           // 7    位置
System.out.println("  空白  ".trim());            // 空白（前後の空白除去）

String csv = "りんご,みかん,ぶどう";
String[] parts = csv.split(",");                 // 分割
System.out.println(parts.length);                // 3

文字列の比較は equals で！（重要）

String a = new String("abc");
String b = new String("abc");
System.out.println(a == b);        // false（参照の比較＝当てにならない）
System.out.println(a.equals(b));   // true （中身の比較＝正しい）

数値と文字列の変換

int n = Integer.parseInt("123");        // 文字列 → 整数
String s = String.valueOf(123);         // 整数 → 文字列
double d = Double.parseDouble("3.14");   // 文字列 → 小数
System.out.println(n + 1);   // 124
System.out.println(s + "!"); // 123!
System.out.println(d * 2);   // 6.28
⚠️ 文字列の中身を比べるときは == ではなく必ず .equals()。初心者が最もハマる落とし穴です。

20. ファイル入出力

ファイルへの書き込み・読み込みは java.nio.file を使うと簡単です。下の例はファイルを作って書き込み、読み戻して表示します。

import java.nio.file.Files;
import java.nio.file.Path;
import java.util.List;

public class Main {
    public static void main(String[] args) throws Exception {
        Path path = Path.of("memo.txt");

        // 書き込み（リストの各要素が1行になる）
        Files.write(path, List.of("1行目", "2行目", "3行目"));

        // 読み込み（全行をListで取得）
        List lines = Files.readAllLines(path);
        for (String line : lines) {
            System.out.println("読込: " + line);
        }

        // まるごと1つの文字列で読む
        String all = Files.readString(path);
        System.out.println("文字数: " + all.length());
    }
}
⚠️ ファイル操作は失敗しうる（存在しない・権限がない等）ので IOException が発生する可能性があります。上の例では main に throws Exception を付けて簡略化しています。実務では try-catch で処理します。

21. ラムダ式とStream

現代のJavaでよく使う書き方。ループを書かずにデータを処理できます。

ラムダ式（短い関数）

import java.util.List;

List names = List.of("佐藤", "鈴木", "田中");
names.forEach(name -> System.out.println(name));  // 各要素に処理

Stream（一覧データの加工）

import java.util.List;

List nums = List.of(1, 2, 3, 4, 5, 6);

int sum = nums.stream()
              .filter(n -> n % 2 == 0)  // 偶数だけ → 2,4,6
              .mapToInt(n -> n * 10)    // 10倍     → 20,40,60
              .sum();                   // 合計
System.out.println(sum); // 120

もう一例：変換して集める

import java.util.List;
import java.util.stream.Collectors;

List names = List.of("sato", "suzuki", "tanaka");

List upper = names.stream()
        .map(String::toUpperCase)   // 大文字に変換
        .filter(s -> s.length() >= 5) // 5文字以上
        .collect(Collectors.toList());

System.out.println(upper); // [SUZUKI, TANAKA]
💡 filter（絞り込み）→ map（変換）→ collect / sum（まとめる）の流れ。String::toUpperCase は「メソッド参照」という短縮記法です。

Q5. 文字列が回文（前から読んでも後ろから読んでも同じ）か判定。

解答を見る 
public class Main {
    static boolean isPalindrome(String s) {
        int i = 0, j = s.length() - 1;
        while (i < j) {
            if (s.charAt(i) != s.charAt(j)) return false;
            i++; j--;
        }
        return true;
    }
    public static void main(String[] args) {
        System.out.println(isPalindrome("level")); // true
        System.out.println(isPalindrome("java"));  // false
    }
}

25. 用語集

つまずきやすい用語を、ひとことで。

変数
データを入れておく名前付きの箱。
型（データ型）
データの種類。int（整数）、String（文字列）など。
メソッド
名前をつけてまとめた処理。関数のこと。
引数（ひきすう）
メソッドに渡す入力データ。
戻り値（もどりち）
メソッドが返す結果。return で返す。
クラス
オブジェクトの設計図。データと処理をまとめたもの。
オブジェクト / インスタンス
クラスから new で作った実物。
フィールド
クラスが持つデータ（変数）。属性。
コンストラクタ
new 時に呼ばれる初期化用の特別なメソッド。
this
「自分自身のオブジェクト」を指すキーワード。
継承
既存クラスの機能を引き継いで新クラスを作ること（extends）。
オーバーライド
親クラスのメソッドを子クラスで上書きすること。
オーバーロード
同じ名前で引数違いのメソッドを複数定義すること。
インターフェース
「できること」だけを定めた約束（implements）。
カプセル化
データを隠してメソッド経由で操作させ、安全にする考え方。
ポリモーフィズム
同じ呼び出しが対象の型で違う動きをすること（多態性）。
例外
実行中に起きるエラー。try-catchで対処する。
コレクション
List・Map・Setなど、データをまとめて扱う道具。
ジェネリクス
型を後から指定できる仕組み。List<String> など。
コンパイル
ソースコードを機械が実行できる形式に変換すること。
JVM
Java仮想マシン。バイトコードを実行する土台。
API
あらかじめ用意された機能の呼び出し口（標準ライブラリなど）。
