1. Javaとは / 環境構築

Java は世界中で広く使われているプログラミング言語です。Androidアプリ、業務システム、Webサーバーなど活躍の場が非常に広く、一度学ぶと長く役立ちます。

Javaの特徴

  • オブジェクト指向 … プログラムを「モノ（オブジェクト）」の集まりとして組み立てる
  • プラットフォーム非依存 … 「一度書けば、どこでも動く（Write Once, Run Anywhere）」
  • 静的型付け … 変数の型をあらかじめ決めるので、間違いに気づきやすい

仕組み（コンパイルと実行）

Javaのソースコード（.java）は コンパイル されて中間形式（.class = バイトコード）になり、それを JVM（Java仮想マシン） が実行します。

Hello.java  --[コンパイル javac]-->  Hello.class  --[実行 java]-->  結果

環境構築（JDKのインストール）

JavaのプログラムをつくるにはJDK（Java Development Kit）が必要です。無料の Temurin（Adoptium） や Oracle JDK をインストールしましょう。インストール後、ターミナル（コマンドプロンプト / PowerShell）で次を実行して確認します。

java -version
javac -version
💡 バージョン番号が表示されればインストール成功です。エディタは VS Code（拡張機能「Extension Pack for Java」）や IntelliJ IDEA がおすすめ。

2. 最初のプログラム（Hello World）

まずは画面に文字を表示する定番プログラムから。Hello.java という名前で保存します。

public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

実行方法

javac Hello.java   # コンパイル → Hello.class が生成される
java Hello         # 実行 → Hello, World! と表示

コードの意味

  • public class Hello … クラスの定義。ファイル名（Hello.java）とクラス名（Hello）は一致させる
  • public static void main(String[] args) … プログラムの入口（mainメソッド）。実行するとここから始まる
  • System.out.println(...) … 画面に1行表示する命令。printlnは改行あり、printは改行なし
  • 文の終わりには必ず セミコロン ; をつける
💡 ブロックは { } で囲みます。インデント（字下げ）を揃えると読みやすくなります。

3. 変数とデータ型

変数はデータを入れておく「箱」です。Javaでは箱を作るときに型（データの種類）を指定します。

int age = 20;            // 整数
double height = 170.5;   // 小数
char grade = 'A';        // 1文字（シングルクォート）
boolean isStudent = true;// 真偽値（true / false）
String name = "佐藤";     // 文字列（ダブルクォート）

基本データ型（プリミティブ型）

型用途例
int整数100, -5
long大きな整数10000000000L
double小数3.14, -0.5
char1文字'A', 'あ'
boolean真偽値true, false

String（文字列）はプリミティブ型ではなくクラスですが、基本としてよく使います。

変数のルール

int score;        // 宣言だけ
score = 80;        // 後から代入
int x = 1, y = 2;  // まとめて宣言

final double PI = 3.14159;  // final = 変更できない定数
// PI = 3.0;  // ← これはエラーになる

型変換（キャスト）

int i = 10;
double d = i;          // int → double は自動変換
double pi = 3.99;
int n = (int) pi;      // double → int は明示的にキャスト（小数点以下切り捨て → 3）
💡 変数名は意味が分かる英単語で。Javaの慣習では userName のように「キャメルケース」を使います。

4. 演算子

算術演算子

int a = 7, b = 3;
System.out.println(a + b); // 10  足し算
System.out.println(a - b); // 4   引き算
System.out.println(a * b); // 21  掛け算
System.out.println(a / b); // 2   割り算（整数同士は小数切り捨て！）
System.out.println(a % b); // 1   余り（あまり）

System.out.println(7.0 / 3); // 2.333... 片方が小数なら小数で計算

代入演算子

int n = 10;
n += 5;  // n = n + 5 → 15
n -= 3;  // 12
n *= 2;  // 24
n++;     // 25（1増やす）
n--;     // 24（1減らす）

比較演算子（結果は boolean）

int x = 5;
System.out.println(x == 5);  // true   等しい
System.out.println(x != 3);  // true   等しくない
System.out.println(x > 3);   // true   より大きい
System.out.println(x <= 5);  // true   以下

論理演算子

boolean a = true, b = false;
System.out.println(a && b);  // false  かつ（AND）
System.out.println(a || b);  // true   または（OR）
System.out.println(!a);      // false  否定（NOT）
⚠️ 整数同士の割り算は要注意！ 5 / 2 は 2 になります（小数は切り捨て）。2.5 がほしいなら 5.0 / 2 とします。

5. 標準入出力

出力

System.out.println("改行あり");
System.out.print("改行");
System.out.print("なし\n");          // \n で改行
System.out.printf("%sは%d歳%n", "佐藤", 20); // 書式つき出力

キーボードから入力（Scanner）

import java.util.Scanner;

public class InputExample {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("名前を入力: ");
        String name = sc.nextLine();   // 1行（文字列）読み取り

        System.out.print("年齢を入力: ");
        int age = sc.nextInt();        // 整数を読み取り

        System.out.println(name + "さんは" + age + "歳です");
        sc.close();
    }
}
  • nextLine() … 1行（文字列）を読む
  • nextInt() … 整数を読む / nextDouble() … 小数を読む
  • 文字列の連結は + でできる
💡 import java.util.Scanner; はファイルの先頭に書きます。「Scannerという道具を使います」という宣言です。

6. 条件分岐 (if / switch)

if 文

int score = 75;

if (score >= 80) {
    System.out.println("優");
} else if (score >= 60) {
    System.out.println("良");
} else {
    System.out.println("不可");
}

三項演算子（短い条件分岐）

int n = 4;
String result = (n % 2 == 0) ? "偶数" : "奇数";
System.out.println(result); // 偶数

switch 文

int day = 3;
switch (day) {
    case 1: System.out.println("月曜"); break;
    case 2: System.out.println("火曜"); break;
    case 3: System.out.println("水曜"); break;
    default: System.out.println("その他"); break;
}

// 新しい書き方（switch式）
String name = switch (day) {
    case 1 -> "月曜";
    case 2 -> "火曜";
    case 3 -> "水曜";
    default -> "その他";
};
⚠️ 従来の switch では break; を忘れると次のcaseまで実行されてしまいます（フォールスルー）。

7. 繰り返し (for / while)

for 文

// 1から5まで表示
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

構造： for (初期化; 続ける条件; 更新)

while 文

int i = 1;
while (i <= 5) {
    System.out.println(i);
    i++;  // ← これを忘れると無限ループ！
}

do-while 文（最低1回は実行）

int n = 10;
do {
    System.out.println(n);
    n--;
} while (n > 0);

break と continue

for (int i = 1; i <= 10; i++) {
    if (i == 5) break;       // ループを抜ける
    if (i % 2 == 0) continue;// 次の繰り返しへスキップ
    System.out.println(i);   // 1, 3 を表示
}
💡 回数が決まっているなら for、条件次第で回数が変わるなら while が使いやすいです。

8. 配列

配列は同じ型のデータをまとめて扱う入れ物です。

// 宣言と初期化
int[] scores = {80, 90, 75, 60};

System.out.println(scores[0]);     // 80（最初は0番目）
System.out.println(scores.length); // 4（要素数）

scores[1] = 100;  // 値の書き換え

// サイズだけ指定して作る
int[] nums = new int[3];  // {0, 0, 0}
nums[0] = 10;

配列のループ処理

int[] scores = {80, 90, 75};

// 通常のfor
for (int i = 0; i < scores.length; i++) {
    System.out.println(scores[i]);
}

// 拡張for文（for-each）… 全要素を順番に
for (int s : scores) {
    System.out.println(s);
}

2次元配列

int[][] table = {
    {1, 2, 3},
    {4, 5, 6}
};
System.out.println(table[1][2]); // 6
⚠️ 存在しない番号にアクセスすると ArrayIndexOutOfBoundsException エラーになります。番号は 0 〜 length-1 まで。

9. メソッド

メソッドは処理に名前をつけてまとめたもの。同じ処理を何度も書かずに再利用できます。

public class MethodExample {

    // 戻り値あり：2つの整数を足して返す
    static int add(int a, int b) {
        return a + b;
    }

    // 戻り値なし：void
    static void greet(String name) {
        System.out.println("こんにちは、" + name + "さん");
    }

    public static void main(String[] args) {
        int sum = add(3, 5);   // 呼び出し
        System.out.println(sum); // 8
        greet("田中");
    }
}

メソッドの構造

戻り値の型  メソッド名(引数の型 引数名, ...) {
    処理
    return 戻り値;   // 戻り値がvoidなら不要
}

オーバーロード（同名で引数違い）

static int add(int a, int b)         { return a + b; }
static double add(double a, double b){ return a + b; }
// 引数の型・数が違えば、同じ名前のメソッドを複数定義できる
💡 「引数（ひきすう）」＝メソッドに渡す入力、「戻り値（もどりち）」＝メソッドが返す結果。

10. クラスとオブジェクト

Javaの中心となる考え方です。クラスは「設計図」、オブジェクト（インスタンス）は設計図から作った「実物」です。

// 設計図（クラス）
class Person {
    String name;  // フィールド（属性）
    int age;

    // コンストラクタ（生成時に呼ばれる初期化処理）
    Person(String name, int age) {
        this.name = name;  // this = 自分自身のフィールド
        this.age = age;
    }

    // メソッド（振る舞い）
    void introduce() {
        System.out.println("私は" + name + "、" + age + "歳です");
    }
}

public class Main {
    public static void main(String[] args) {
        // 実物（オブジェクト）を作る
        Person p1 = new Person("佐藤", 20);
        Person p2 = new Person("鈴木", 25);

        p1.introduce(); // 私は佐藤、20歳です
        p2.introduce(); // 私は鈴木、25歳です

        System.out.println(p1.name); // フィールドにアクセス
    }
}
  • フィールド … オブジェクトが持つデータ（name, age）
  • メソッド … オブジェクトの動作（introduce）
  • コンストラクタ … new したときに自動で呼ばれる。初期値の設定に使う
  • this … 「自分自身のオブジェクト」を指す

11. カプセル化（アクセス修飾子）

フィールドを外から勝手に書き換えられないように隠し、専用のメソッド（getter / setter）を通してアクセスさせる仕組みです。安全なプログラムの基本。

class BankAccount {
    private int balance = 0;   // private = クラスの外から直接触れない

    // 預け入れ（不正な値をチェックできる）
    public void deposit(int amount) {
        if (amount > 0) {
            balance += amount;
        }
    }

    // 残高を取得（getter）
    public int getBalance() {
        return balance;
    }
}

public class Main {
    public static void main(String[] args) {
        BankAccount acc = new BankAccount();
        acc.deposit(1000);
        // acc.balance = -999;  // ← privateなのでエラー（守られる）
        System.out.println(acc.getBalance()); // 1000
    }
}

アクセス修飾子

修飾子アクセスできる範囲
publicどこからでも
protected同じパッケージ＋サブクラス
(なし)同じパッケージ内
private同じクラス内のみ
💡 「フィールドはprivate、操作はpublicメソッドで」が基本パターンです。

12. 継承

継承は既存のクラスの機能を引き継いで、新しいクラスを作る仕組みです。共通部分を親クラスにまとめられます。

// 親クラス（スーパークラス）
class Animal {
    String name;
    Animal(String name) { this.name = name; }

    void eat() {
        System.out.println(name + "は食べる");
    }
}

// 子クラス（サブクラス）… extends で継承
class Dog extends Animal {
    Dog(String name) {
        super(name);  // 親のコンストラクタを呼ぶ
    }

    // 子クラス独自のメソッド
    void bark() {
        System.out.println(name + "はワンと鳴く");
    }
}

public class Main {
    public static void main(String[] args) {
        Dog dog = new Dog("ポチ");
        dog.eat();  // 親から継承 → ポチは食べる
        dog.bark(); // 子で追加   → ポチはワンと鳴く
    }
}

オーバーライド（親のメソッドを上書き）

class Cat extends Animal {
    Cat(String name) { super(name); }

    @Override
    void eat() {  // 親のeatを上書き
        System.out.println(name + "は魚を食べる");
    }
}
💡 @Override は「親のメソッドを上書きします」という目印。書いておくと書き間違いを防げます。

13. ポリモーフィズム / 抽象クラス

ポリモーフィズム（多態性）は、同じ呼び出しでもオブジェクトの種類によって違う動きをすることです。

Animal[] animals = { new Dog("ポチ"), new Cat("タマ") };

for (Animal a : animals) {
    a.eat();   // 同じ a.eat() でも、実際の型に応じて動きが変わる
}
// ポチは食べる
// タマは魚を食べる

抽象クラス（abstract）

「中身が未定のメソッド」を持つ、継承されることが前提のクラスです。直接newできません。

abstract class Shape {
    abstract double area();  // 中身なし。子クラスで必ず実装させる

    void show() {
        System.out.println("面積は " + area());
    }
}

class Circle extends Shape {
    double r;
    Circle(double r) { this.r = r; }

    @Override
    double area() { return r * r * 3.14; }  // 実装する
}

public class Main {
    public static void main(String[] args) {
        Shape s = new Circle(2);
        s.show(); // 面積は 12.56
    }
}

14. インターフェース

インターフェースは「できること（メソッドの一覧）」だけを定めた約束ごとです。実装クラスは、その約束を必ず守ります。複数のインターフェースを同時に実装できます。

// インターフェース定義
interface Flyable {
    void fly();  // 中身は書かない（実装はクラス側で）
}

interface Swimmable {
    void swim();
}

// implements で実装（複数OK）
class Duck implements Flyable, Swimmable {
    @Override
    public void fly()  { System.out.println("カモが飛ぶ"); }
    @Override
    public void swim() { System.out.println("カモが泳ぐ"); }
}

public class Main {
    public static void main(String[] args) {
        Duck duck = new Duck();
        duck.fly();
        duck.swim();
    }
}

抽象クラスとの違い

抽象クラスインターフェース
継承/実装extends（1つだけ）implements（複数OK）
用途共通の土台（is-a）できることの約束（can-do）

15. 例外処理

プログラム実行中のエラー（例外）に対処する仕組みです。落ちずに対応できます。

public class Main {
    public static void main(String[] args) {
        try {
            int[] arr = {1, 2, 3};
            System.out.println(arr[10]); // 範囲外！ 例外発生
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("配列の範囲外です: " + e.getMessage());
        } finally {
            System.out.println("最後に必ず実行される");
        }
    }
}
  • try … エラーが起こりそうな処理を囲む
  • catch … 例外が起きたときの処理
  • finally … 例外の有無にかかわらず必ず実行（後片付けに使う）

例外を自分で投げる（throw）

static int divide(int a, int b) {
    if (b == 0) {
        throw new IllegalArgumentException("0で割れません");
    }
    return a / b;
}
⚠️ よく出会う例外： NullPointerException（nullを使った）、NumberFormatException（数値変換失敗）、ArrayIndexOutOfBoundsException（配列範囲外）。

16. コレクション（List / Map / Set）

配列より柔軟にデータを扱える仕組み。サイズが自由に変わります。

ArrayList（順番に並ぶリスト）

import java.util.ArrayList;
import java.util.List;

List fruits = new ArrayList<>();
fruits.add("りんご");
fruits.add("みかん");
fruits.add("ぶどう");

System.out.println(fruits.get(0));  // りんご
System.out.println(fruits.size());  // 3
fruits.remove("みかん");

for (String f : fruits) {
    System.out.println(f);
}

HashMap（キーと値のペア）

import java.util.HashMap;
import java.util.Map;

Map scores = new HashMap<>();
scores.put("佐藤", 80);
scores.put("鈴木", 95);

System.out.println(scores.get("鈴木")); // 95

for (Map.Entry e : scores.entrySet()) {
    System.out.println(e.getKey() + ": " + e.getValue());
}

HashSet（重複なしの集合）

import java.util.HashSet;
import java.util.Set;

Set set = new HashSet<>();
set.add("A");
set.add("A");  // 重複は無視される
set.add("B");
System.out.println(set.size()); // 2
💡 <String> の部分はジェネリクス。「このリストには文字列を入れる」と型を指定しています。

17. 文字列操作

String s = "Hello, Java";

System.out.println(s.length());          // 11  文字数
System.out.println(s.charAt(0));         // H   指定位置の文字
System.out.println(s.substring(7));      // Java 部分文字列
System.out.println(s.toUpperCase());     // HELLO, JAVA
System.out.println(s.replace("Java", "World")); // Hello, World
System.out.println(s.contains("Java"));  // true
System.out.println(s.indexOf("Java"));   // 7   位置
System.out.println("  空白  ".trim());    // "空白"（前後の空白除去）

// 分割
String csv = "りんご,みかん,ぶどう";
String[] parts = csv.split(",");  // ["りんご","みかん","ぶどう"]

文字列の比較は equals で！

String a = "abc";
String b = "abc";
System.out.println(a == b);        // 当てにならない（参照の比較）
System.out.println(a.equals(b));   // true ← 正しい中身の比較

数値と文字列の変換

int n = Integer.parseInt("123");      // 文字列 → 整数
String s = String.valueOf(123);       // 整数 → 文字列
double d = Double.parseDouble("3.14");
⚠️ 文字列の中身を比べるときは == ではなく必ず .equals() を使いましょう。これは初心者がよくハマる落とし穴です。

18. ラムダ式とStream（発展）

少し進んだ書き方ですが、現代のJavaでよく使われます。今は「こういうものがある」と知る程度でOK。

ラムダ式（短い関数の書き方）

import java.util.List;

List names = List.of("佐藤", "鈴木", "田中");

// forEach + ラムダ式
names.forEach(name -> System.out.println(name));

Stream（一覧データの加工）

import java.util.List;

List nums = List.of(1, 2, 3, 4, 5, 6);

int sum = nums.stream()
              .filter(n -> n % 2 == 0)   // 偶数だけ
              .mapToInt(n -> n * 10)     // 10倍
              .sum();                    // 合計
System.out.println(sum); // 120 (2*10 + 4*10 + 6*10)
💡 filter（絞り込み）→ map（変換）→ collect/sum（まとめる）という流れで、ループを書かずにデータを処理できます。

19. 練習問題

import java.util.List;

public class Q4 {

Q5. 文字列を受け取り、それが回文（前から読んでも後ろから読んでも同じ）かどうか判定してください。

解答を見る 
public class Q5 {
    static boolean isPalindrome(String s) {
        int i = 0, j = s.length() - 1;
        while (i < j) {
            if (s.charAt(i) != s.charAt(j)) return false;
            i++;
            j--;
        }
        return true;
    }
    public static void main(String[] args) {
        System.out.println(isPalindrome("level")); // true
        System.out.println(isPalindrome("java"));  // false
    }
}
