🔀 制御構文

プログラムの流れを操る基本：条件で分けたり、繰り返したり。配列とメソッドで、まとまった処理が書けるようになります。

6. 条件分岐 (if / switch)

if 文

int score = 75;

if (score >= 80) {
    System.out.println("優");
} else if (score >= 60) {
    System.out.println("良");
} else {
    System.out.println("不可");
}

三項演算子（短い条件分岐）

int n = 4;
String result = (n % 2 == 0) ? "偶数" : "奇数";
System.out.println(result); // 偶数

switch 文・switch式

int day = 3;

// 新しい書き方（switch式）：すっきり書ける
String name = switch (day) {
    case 1 -> "月曜";
    case 2 -> "火曜";
    case 3 -> "水曜";
    default -> "その他";
};
System.out.println(name); // 水曜
⚠️ 従来の switch(){ case ...: break; } では break; を忘れると次のcaseまで実行されます（フォールスルー）。新しい -> 形式ならその心配はありません。

7. 繰り返し (for / while)

for 文

// 1から5まで表示
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

構造： for (初期化; 続ける条件; 更新)

while / do-while

int i = 1;
while (i <= 3) {
    System.out.println("while: " + i);
    i++;  // ← 忘れると無限ループ！
}

int n = 3;
do {
    System.out.println("do-while: " + n); // 最低1回は実行される
    n--;
} while (n > 0);

break と continue

for (int i = 1; i <= 10; i++) {
    if (i == 5) break;        // ループを抜ける
    if (i % 2 == 0) continue; // 次の繰り返しへスキップ
    System.out.println(i);    // 1, 3 を表示
}
💡 回数が決まっているなら for、条件次第で変わるなら while。

8. 配列

配列は同じ型のデータをまとめて扱う入れ物。番号（インデックス）は 0から始まります。

0123
80907560
int[] scores（length = 4）
int[] scores = {80, 90, 75, 60};

System.out.println(scores[0]);     // 80（最初は0番目）
System.out.println(scores.length); // 4（要素数）

scores[1] = 100;                   // 値の書き換え

// 拡張for文（for-each）… 全要素を順番に
for (int s : scores) {
    System.out.println(s);
}

2次元配列

int[][] table = {
    {1, 2, 3},
    {4, 5, 6}
};
System.out.println(table[1][2]); // 6
⚠️ 存在しない番号にアクセスすると ArrayIndexOutOfBoundsException。番号は 0 〜 length-1 まで。上のコードで scores[10] を表示しようとするとどうなるか試してみよう。

9. メソッド

メソッドは処理に名前をつけてまとめたもの。同じ処理を何度も書かずに再利用できます。

public class Main {

    // 戻り値あり：2つの整数を足して返す
    static int add(int a, int b) {
        return a + b;
    }

    // 戻り値なし：void
    static void greet(String name) {
        System.out.println("こんにちは、" + name + "さん");
    }

    public static void main(String[] args) {
        int sum = add(3, 5);     // 呼び出し
        System.out.println(sum); // 8
        greet("田中");
    }
}

メソッドの構造

戻り値の型  メソッド名(引数の型 引数名, ...) {
    処理
    return 戻り値;   // 戻り値がvoidなら不要
}

オーバーロード（同名で引数違い）

public class Main {
    static int add(int a, int b)          { return a + b; }
    static double add(double a, double b) { return a + b; }

    public static void main(String[] args) {
        System.out.println(add(2, 3));     // int版 → 5
        System.out.println(add(2.5, 0.5)); // double版 → 3.0
    }
}
💡 「引数（ひきすう）」＝メソッドに渡す入力、「戻り値（もどりち）」＝返す結果。引数の型・数が違えば同じ名前で複数定義できます（オーバーロード）。
