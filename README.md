# ☕ Java基礎マスター

Javaの基礎をゼロから体系的に学べる学習用Webサイトです。自分の勉強用に作成しました。

## 📖 公開ページ

👉 **https://alice3589.github.io/java-basics/**

## 内容（全20章）

| 章 | テーマ |
|----|--------|
| 1〜5 | Javaとは・環境構築 / Hello World / 変数とデータ型 / 演算子 / 標準入出力 |
| 6〜9 | 条件分岐 / 繰り返し / 配列 / メソッド |
| 10〜14 | クラスとオブジェクト / カプセル化 / 継承 / ポリモーフィズム / インターフェース |
| 15〜18 | 例外処理 / コレクション / 文字列操作 / ラムダ式とStream |
| 19〜20 | 練習問題（解答つき） / 次のステップ |

## 特徴

- 📋 すべてのコード例にワンクリックのコピーボタン
- 🎨 シンタックスハイライト（Prism.js）
- 📱 スマホ・タブレット対応のレスポンシブデザイン
- ✏️ 解答を隠せる練習問題

## ローカルで開く

`index.html` をブラウザで開くだけで動作します（ビルド不要）。

## ファイル構成

```
java-basics/
├── index.html   本体（全コンテンツ）
├── style.css    スタイル
├── script.js    コピーボタン・ナビ・ハイライト
└── README.md
```
