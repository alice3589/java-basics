# ☕ Java基礎マスター

Javaの基礎をゼロから体系的に学べる学習用Webサイトです。**ブラウザ上でコードをその場で実行**しながら学べます。自分の勉強用に作成しました。

## 📖 公開ページ

👉 **https://alice3589.github.io/java-basics/**

## ✨ 特徴

- 🟢 **ブラウザ内でJavaを実行** — 各コード例の「▶ 実行」ボタンでその場でコンパイル＆実行。コードを書き換えて再実行も可能（[Wandbox](https://wandbox.org) JDK 22 を利用）
- 🎮 **プレイグラウンド** — 自由にコードを書いて試せるエディタ（CodeMirror）
- ❓ **理解度クイズ** — 章ごとに選択式クイズ。即時採点・解説つき
- 📊 **進捗トラッキング** — 「学習済み」を記録し、進捗バーで可視化（localStorage）
- 🌗 **ライト / ダークテーマ切り替え**
- 🔍 **章の検索**
- 📋 コードのコピー、シンタックスハイライト、図解
- 📱 スマホ・タブレット対応のレスポンシブデザイン

## ローカルで開く

`index.html` をブラウザで開くだけで動作します（ビルド不要）。コード実行機能はインターネット接続が必要です。

## ファイル構成

```
java-basics/
├── index.html     本体（全コンテンツ）
├── style.css      スタイル（ライト/ダーク両対応）
├── script.js      実行・クイズ・進捗・検索・テーマ等のロジック
├── quiz-data.js   各章のクイズデータ
└── README.md
```

## 技術メモ

- コード実行: Wandbox API（`https://wandbox.org/api/compile.json`、`openjdk-jdk-22+36`）。CORS開放済みでブラウザから直接呼び出し。
- 実行時、Wandboxのメインファイルは `prog.java` のため、`public class` は `class` に変換して送信している。
- 文・式だけのスニペット例（`data-wrap="main"`）は、import行を先頭に集めて `main` メソッドで自動的に包んで実行する。
